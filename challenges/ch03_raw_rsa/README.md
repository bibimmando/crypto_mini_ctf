# CH03 패딩을 잊은 RSA

개발자는 RSA 수식을 그대로 옮겨 짧은 메시지를 암호화했다. 키 크기는 2048비트이고 공개 지수는 3이다. 공개키와 암호문만으로 flag를 찾을 수 있을까?

제공 파일은 `vulnerable.py`와 `challenge.json`이다. 개인키와 소인수는 제공하지 않는다.

`challenge.json`의 `n`은 모듈러스, `e`는 공개 지수, `c`는 암호문이다. `n`과 `c`는 큰 정수의 십진 문자열이므로 `int()`로 읽으면 된다. 메시지는 big-endian 바이트를 정수로 바꾼 값이다.

이 문제의 메시지는 충분히 짧아 `m ** 3 < n`을 만족한다. 소인수분해 없이 풀 수 있다.

<details>
<summary>힌트</summary>

`m ** 3`이 `n`보다 작으면 나머지 연산을 해도 값이 바뀌지 않는다. 큰 정수의 세제곱근은 부동소수점 대신 이진 탐색으로 구해보자.

</details>
